## Taller 1 — Primer taller de seguridad de la información

📄 [**Ver informe completo (PDF)**](Taller1_Seguridad.pdf)

**Resumen:**
Explotación de la vulnerabilidad MS17-010 (EternalBlue) sobre un entorno
virtualizado para obtener una sesión Meterpreter y demostrar el impacto
real de técnicas de post-explotación sobre un equipo comprometido.

**Actividades desarrolladas:**
1. Captura de streaming
2. Captura de teclado
3. Control de consola
4. Acceso a cámara
5. Capturas de pantalla cada x min
